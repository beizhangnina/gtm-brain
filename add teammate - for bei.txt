GTM Brain：给同事开通 / 注销（阿蓓专用）
==========================================

每个同事一套独立的「只读」凭证：
  - 只能搜、只能读，改不了库里的内容
  - 可以单独注销，注销后立刻失效，不影响其他人
  - 同事装一次就永远不用管，不会过期
  - 同事用 Claude Code、Codex 都行，两个都有就两个都装

凭证不会显示在屏幕上，下面所有命令的输出都可以放心给别人看（最多只有 client_id，它不是机密）。


------------------------------------------
零、前提（只需要确认一次）
------------------------------------------

1. Railway 已登录。检查方法：在终端运行
       railway whoami
   显示 "Logged in as ..." 就行。没登录的话运行 railway login，按提示在浏览器里登录。

2. 名字的规则：只用小写英文、数字、- 和 _
   可以：zhen、alice、bob-chen
   不行：Zhen、张三、bob chen


------------------------------------------
一、给同事开通
------------------------------------------

【方式 A：在 Claude Code 里】

  前提：这个 Claude Code 是在 gtm-brain 项目文件夹里打开的
  （~/Documents/AI_Dev/gtm-brain）。

  在对话框里输入（前面的 ! 一定要加）：

      ! bin/onboard-teammate 名字

  例如：

      ! bin/onboard-teammate alice

  注意：
  - 一定要加 !。加了 ! 是你自己在运行，结果直接显示在对话里。
  - 不要说「帮我给 alice 开通」让 Claude 去跑。签发凭证会被权限系统拦下，
    这是故意的：签发凭证必须你本人来做。


【方式 B：在终端（Terminal）里】

      cd ~/Documents/AI_Dev/gtm-brain
      bin/onboard-teammate alice


【两种方式运行完都会看到】

      ✓ 已生成 .../onboarding/alice-install.sh
        client_id: gbrain_cl_xxxxxxxx
        发给对方：...
        撤销命令已记进 onboarding/clients.log

  生成的安装文件在：
      ~/Documents/AI_Dev/gtm-brain/onboarding/alice-install.sh

  同时会自动在台账里记一行（名字、日期、client_id、注销命令）：
      ~/Documents/AI_Dev/gtm-brain/onboarding/clients.log


------------------------------------------
二、把安装文件发给同事
------------------------------------------

  这个文件里有对方的个人凭证，拿到文件的人就能读整个库（包括付费内容）。

  推荐：
    - 在同一个办公室：AirDrop（点对点，不经过云端，最安全）
    - 远程：Slack / 微信 / 飞书「私聊」发文件，对方装好后把那条消息删掉

  不要：
    - 发到群聊或频道
    - 发邮件
    - 放进网盘共享文件夹、提交到 git


------------------------------------------
三、同事那边怎么装（把这段转给他）
------------------------------------------

  1. 打开「终端」（Terminal），进入安装文件所在的文件夹，比如下载目录：
         cd ~/Downloads
  2. 运行：
         bash alice-install.sh
  3. 看到「✓ 完成，已装进 Claude Code 和 Codex」（或其中一个）就好了
  4. 新开一个 Claude Code 会话；用 Codex 的话，要彻底退出并重新打开 ChatGPT App
  5. 直接问 GTM 问题就行，不用说「用 gtm-brain」，例如：
         B2B SaaS 首页定位有哪些好的改版案例？给我三个，说说改前改后的区别

  注意：同事必须在「终端」里运行，不能在他自己的 Claude Code 里用 ! 运行
  （他的 Claude Code 里没有这个项目）。

  需要：装了 Claude Code 或 Codex 其中之一；Mac 自带的 python3 就够，不用装别的。

  装好后，他的电脑上会有这些东西：
    ~/.config/gtm-brain/     凭证和连接小脚本（权限只有他自己能读）
    Claude Code 里的 gtm-brain 配置
    ~/.codex/config.toml 里的 gtm-brain 一段（如果有 Codex）
    ~/.claude/CLAUDE.md 和 ~/.codex/AGENTS.md 里「GTM 问题先查 gtm-brain」的规则


------------------------------------------
四、查看已经给谁开通了
------------------------------------------

  最简单：打开台账文件
      ~/Documents/AI_Dev/gtm-brain/onboarding/clients.log
  每行是：日期  名字  client_id  注销命令

  或者直接问服务器（包括谁最近在用）：

  【Claude Code 里】
      ! railway ssh -s gtm-brain bun /app/src/cli.ts auth clients --usage

  【终端里】
      cd ~/Documents/AI_Dev/gtm-brain
      railway ssh -s gtm-brain bun /app/src/cli.ts auth clients --usage


------------------------------------------
五、注销同事（离职、发错人、怀疑泄露）
------------------------------------------

  第 1 步：找到这个人的 client_id
      打开 onboarding/clients.log，找到他那一行，最后一列就是完整的注销命令，直接复制。

      也可以在终端里用名字搜：
          cd ~/Documents/AI_Dev/gtm-brain
          grep alice onboarding/clients.log

  第 2 步：运行注销命令

  【Claude Code 里】（同样要加 !）
      ! railway ssh -s gtm-brain bun /app/src/cli.ts auth revoke-client gbrain_cl_xxxxxxxx

  【终端里】
      cd ~/Documents/AI_Dev/gtm-brain
      railway ssh -s gtm-brain bun /app/src/cli.ts auth revoke-client gbrain_cl_xxxxxxxx

  注意：注销用的是 client_id（gbrain_cl_ 开头那一长串），不是名字。

  效果：立刻生效。他手上的凭证和已经换到的 token 全部作废，下次提问就连不上了。
        其他同事完全不受影响。

  第 3 步（收尾）：
    - 删掉他的安装文件：
          rm ~/Documents/AI_Dev/gtm-brain/onboarding/alice-install.sh
    - 在 clients.log 里他那一行前面加一句「已注销 2026-xx-xx」，方便以后查

  想给他重新开通：再跑一次 bin/onboard-teammate alice 就行，会生成一套全新的凭证。


------------------------------------------
六、常见问题
------------------------------------------

  Q：运行 onboard-teammate 报「注册失败」
  A：多半是 Railway 没登录或登录过期了。终端里运行 railway login，再重试。

  Q：同事装的时候报「凭证换不到 token」
  A：可能是凭证已被注销，或者他的网络连不上。给他重新开通一次，把新文件发过去。

  Q：同事装好了，但 Claude 回答时没有去查库
  A：1) 确认他新开了会话 / 重启了 ChatGPT App
     2) 让他在 Claude Code 里输入 /mcp，看 gtm-brain 是不是 connected
     3) 让他在终端运行 python3 ~/.config/gtm-brain/headers.py，把报错发给你（不会显示密码）

  Q：同一个人换了电脑
  A：把原来的 alice-install.sh 发给他，在新电脑上再运行一次就行，不用重新开通。
     如果旧电脑不在他手上了（丢了、交还公司），先注销，再重新开通。

  Q：给同一个名字开通了两次会怎样
  A：会生成两套独立的凭证，两套都能用。不需要的那套按第五步注销掉。
